openclaw-home

openclaw-home is a personal home assistant run by Weihao Li for personal use. It is not offered to anyone else.

With the owner's Google sign-in it can:

  • search and read the owner's Gmail, and create or edit drafts that only the owner can send (it cannot send mail);
  • read the owner's Google Calendar and add events; invitations to other people are sent only after the owner approves each one.

The Google credential is stored encrypted on the owner's home server and is never shared.
